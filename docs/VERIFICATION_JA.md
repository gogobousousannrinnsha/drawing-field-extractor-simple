# 図面項目抽出 v0.1.5 検証状況

PDFとXDWを共通OCRへ接続し、保存した画像・OCR・根拠座標から項目を抽出します。座標付きExcelの対象文書に属する全座標行を使い、原本XDWのコピーへ黄色・透過のDocuWorksマーカーを追加できます。

以下は2026年10月13日までの機能別候補の検証結果です。黄色マーカーを統合した公開版のCPU再試験・配布監査は、新規展開した最終ソースZIPを対象に実施し、公開準備記録とReleaseの説明でZIPのSHA-256と対応させて記録します。

## 確認済み

| 対象 | 結果 |
|---|---|
| 共通OCRのソースZIP | 新規展開・移動後のCPU試験407件成功。ZIPのCRC、収録ファイルのサイズ・SHA-256、同封Core、配布範囲を確認 |
| PDF／XDW入力 | 人工資料各3ページ、計6ページで実GPU OCR成功。縦・横・90度回転ページを含む |
| OCR再利用 | 6ページすべてキャッシュ再利用、OCR再実行0ページ |
| 項目抽出とExcel | Gemma4で6ページ成功。抽出値、根拠ID、Excelの数値座標を保存データと照合 |
| 全文OCR白紙PNG／Excel再出力 | 6ページのPNG出力、警告0。保存結果からの再出力を確認 |
| フォルダー移動・改名 | 構築済み候補を移動・改名し、旧パスがない状態で処理・再出力を確認 |
| 黄色マーカー | 追加機能のCPU試験47件成功。実BATで3ページ・3座標行に6個の真のMARKERを配置し、保存再読込み・Raw属性・SDK画像を確認 |
| マーカー位置・透過 | 回転ページを含め、検証した座標領域外の黄色画素0。領域内の元の暗色文字画素の保持率100% |
| マーカー追加の追加ケース | 再出力Excel、改名XDWの明示対応、PDF由来座標の明示対応、原本不一致の拒否、既存注釈保持、ソース移動など7ケース成功 |
| 原本保持・繰り返し | 原本XDWと入力ExcelのSHA-256不変。同じ原本から2回実行してもマーカーが累積しないことを確認 |

実SDK検証環境はDocuWorks 10.1.1、Core 1.0.1、Python 3.13.15、RTX 3060です。マーカー幅は整数ptで1～13ptに収め、表示ページのmm座標を使用します。既存注釈保持の追加ケースは、人工のstandalone座標行による技術検証です。ソースのみを移動した追加ケースは、既存runtimeを指定して実行しています。

Gemma4のHugging Face代替取得は別の人工接続試料で実取得・SHA-256検査・画像付き推論2ケースに成功し、保存証跡の独立確認35項目も成功しました。取得元の版とモデルの識別情報を固定し、元の取得経路の合格記録を流用しません。元の通信失敗は人工条件であり、実際の企業proxyの再現ではありません。今回の共通OCR候補にはGemma4を導入しており、Gemma3・Salukiの実取得・推論は確認していません。

## 配布と検証の範囲

公開準備の対象はソースZIPと同封Coreです。runtime、モデル本体、DocuWorks SDK DLL、入力文書、個別の処理結果を含めない構成で、利用時には初期設定と必要な外部環境の導入が必要です。構築済みPortableの配布・動作保証とは分けて扱います。

実業務図面の認識・抽出精度、DocuWorks 9.1、Viewerでの手動表示・編集、GUIでのファイル選択、別PC、新しい統合ZIPからの初期設定のやり直しは未検証です。SDKが出力した画像の確認をViewerでの確認として扱いません。人工資料のPDF／XDWは同一の3ページ内容から作成しており、独立した6図面の精度評価ではありません。

既存の407件と47件は各候補での検証数です。統合した公開版に対する新規試験の成功数として合算していません。最終成果物の実行結果とハッシュは、公開準備記録とReleaseの説明を参照してください。
